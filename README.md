# 攀岩初级指导员理论刷题

这是一个纯静态刷题网站，可以直接部署到 GitHub Pages。

## 部署到 GitHub Pages

1. 新建一个公开 GitHub 仓库，例如 `climbing-quiz`。
2. 把本文件夹里的所有文件上传到仓库根目录。
3. 打开仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`，保存。
6. 等待 GitHub Pages 部署完成，访问页面提供的网址。

## 使用说明

- 首次打开会选择 `高频` 或 `全部`。
- 错题、进度和讲解记录保存在当前浏览器本地。
- 手机 Safari/Chrome 可以把网页添加到主屏幕。
- 如果换设备，错题记录不会自动同步。
